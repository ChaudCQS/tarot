# 塔罗抽牌

静态站点，78 张韦特牌、14 种牌阵，抽牌翻牌之后可以接 DeepSeek 生成解读。

分五个页面：首页是门面，牌桌单独一页，牌阵说明、常见问题、隐私各占一页。

## 起服务

```sh
sh start.sh        # 或 sh start.sh 9000 换端口
```

浏览器打开 `http://127.0.0.1:8848/`。要走 http，`file://` 方式下浏览器会拦掉 AI 请求。

页面之间用普通链接跳转，不需要路由；从牌阵总表点某一行的阵名，会带着 `?spread=<id>` 直接落到牌桌上并选中那个阵。

## 填 key

点右上角「设置」填 DeepSeek 的 API key。key 只存本机 `localStorage`，点「清除 key」可删。不填也能用，牌面与牌义都在本地。

| --- | --- |

| `table.html` | 牌桌：控制栏 + 画布 + 解读，设置抽屉也在这页 |
| `spreads.html` | 牌阵说明：三步走完一次占卜、14 种牌阵总表 |
| `faq.html` | 常见问题六条（带 FAQPage 结构化数据） |
| `legal.html` | 隐私与免责 |
| `404.html` | 找不到页面时的兜底 |
| `styles.css` | 视觉系统（间距/字号/圆角/配色 token、动效） |
| `common.js` | 公共交互：移动菜单、滚动揭示、tagline 逐字点亮、首页扇牌演示 |
| `table.js` | 牌桌：抽牌、翻牌、画布排布、解读渲染、流式 AI 请求 |
| `spreads.js` | 渲染牌阵总表（与 `data/spreads.js` 同名不同层，前者是脚本，后者是数据） |
| `data/cards.js` | 78 张牌的名字与正逆位义项 |
| `data/spreads.js` | 14 种牌阵的位置坐标 |

改页面结构时注意：`common.js` 里没有的元素会自动跳过，所以每个页面只引用自己需要的脚本即可。

## 加牌阵

在 `data/spreads.js` 里加一条，写完页面自动出现在选牌菜单里：

```js
{
  id: 'mine', name: '我的牌阵', fit: '适合什么问题',
  desc: '一句话说明', scale: 1,
  positions: [
    { name: '位置名', hint: '这个位置在问什么', x: 1, y: 1 }
  ]
}
```

`x`/`y` 以「格」为单位、从 1 起算，一格 = 一张牌宽，可以写小数（`x: 2.5` 就是落在两张牌中间）。横置的牌加 `rot: 90`，再配 `scale: 0.8` 把它缩一号，免得盖住左右邻牌。纵向长的阵把 spread 级的 `scale` 调到 0.6–0.9，整阵会自动缩小。

牌桌会按容器宽度自动算牌宽（桌面基准 124px、窄屏 86px），加完在手机宽度下看一眼再收工。

## 部署

纯静态，把整个文件夹丢到 GitHub Pages / Cloudflare Pages 即可，不需要构建。牌面走相对路径，换域名不用改代码。

## 动效

抽牌时牌从桌面中心那一叠飞向各自落点，错峰入场；翻牌走 3D 翻转并在牌面上扫过一道高光；解读逐条浮现；AI 解读是流式返回，边生成边显示。首页三张装饰牌进到视口会自己翻开一遍。

全部动画只动 `transform` 与 `opacity`，并尊重 `prefers-reduced-motion`：系统开了「减少动态效果」时一律跳过。
